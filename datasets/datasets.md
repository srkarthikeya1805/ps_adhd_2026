\# Public ADHD EEG Datasets



This project uses three publicly available EEG datasets. The data files themselves are \*\*not\*\* included in this repository. Download them directly from the official sources below, and review and follow the applicable source terms, licence, attribution, and citation requirements before use.



\## 1. IEEE DataPort — EEG Data for ADHD / Control Children



\*\*Official link:\*\* <https://ieee-dataport.org/open-access/eeg-data-adhd-control-children>



This dataset contains EEG recordings from \*\*121 children\*\* aged \*\*7–12 years\*\*: \*\*61 children with ADHD\*\* and \*\*60 healthy controls\*\*. Recordings were collected during a visual-attention task in which children counted cartoon characters. The recordings use the international 10–20 montage with 19 EEG channels and a 128 Hz sampling rate. The source material is distributed as EEG signal data suitable for loading from MATLAB-style data files (commonly used as `.mat` files in analyses of this dataset).



\## 2. Mendeley Data — Adults with ADHD and Healthy Controls



\*\*Official link:\*\* <https://data.mendeley.com/datasets/6k4g25fhzg/1>



This dataset includes EEG recordings from \*\*79 adults\*\* aged \*\*20–68 years\*\*: \*\*37 adults with ADHD\*\* and \*\*42 healthy controls\*\*. It includes recordings from five channels (O1, F3, F4, Cz, and Fz), sampled at 256 Hz, across four conditions: eyes open, eyes closed, a cognitive challenge, and listening to omni-harmonic sound. The download is provided in \*\*MATLAB `.mat` format\*\*, organized into four files for female/male control and female/male ADHD groups.



\## 3. Figshare — EEG Raw Data: Working Memory and Response Inhibition in ADHD



\*\*Official link:\*\* <https://figshare.com/articles/dataset/EEG\_raw\_data\_-\_Economical\_Assessment\_of\_Working\_Memory\_and\_Response\_Inhibition\_in\_ADHD/12115773>



This dataset contains \*\*raw EEG data\*\* from \*\*59 participants\*\* aged \*\*9–16 years\*\*: \*\*34 participants with ADHD\*\* and \*\*25 healthy controls\*\*. It accompanies an ERP study of working memory and response inhibition using single-task and combined 2-back/no-go paradigms. The source provides the raw EEG recordings as a downloadable dataset archive; preserve the source file organization and consult its accompanying documentation when selecting tools for import and preprocessing.



\## Access and reuse



All three datasets are publicly available from the official links above. They remain hosted and governed by IEEE DataPort, Mendeley Data, and Figshare respectively; this repository does not redistribute them. Users are responsible for checking each record's current availability, licence, terms of use, citation guidance, and any access requirements before downloading or using the data.
